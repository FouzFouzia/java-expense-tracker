This is a console-based personal Expense Tracker developed using Core Java.
It helps users manage daily expenses, categorize spending, and generate expense summaries.

🚀 Features
Add Expense (Date, Amount, Category, Description)
View All Expenses
Update & Delete Expenses
Search by Category
Total Expense Calculation
Menu-driven Interface

🛠 Technologies Used
Core Java
OOP Concepts
ArrayList
Iterator
Exception Handling
